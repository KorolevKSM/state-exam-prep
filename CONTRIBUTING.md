# 🚀 Инструкция по работе с репозиторием для контрибьюторов

Прямой пуш в ветку `main` заблокирован в целях безопасности. Вся работа над проектом ведется через создание отдельных веток и **Pull Requests (PR)**. 

Пожалуйста, следуйте этой пошаговой инструкции при добавлении любых материалов или изменений.

---

### Шаг 1. Обновите локальный репозиторий
Перед началом работы убедитесь, что вы находитесь в ветке `main` и скачали самые последние изменения из облака:
```bash
git checkout main
git pull
```

### Шаг 2. Создайте новую ветку под свою задачу
Никогда не делайте изменения в ветке `main`. Создайте новую ветку с понятным названием (например, для решения конкретного кейса):
```bash
git checkout -b feature-case-1
```
*(Вместо `feature-case-1` укажите название вашей задачи).*

### Шаг 3. Зафиксируйте и отправьте изменения
После того как вы добавили или изменили нужные файлы, сделайте коммит и отправьте свою ветку на GitHub:
```bash
# Добавить все измененные файлы в индекс
git add .

# Зафиксировать изменения с понятным комментарием
git commit -m "Добавлено решение и описание для кейса 1"

# Отправить ветку в удаленный репозиторий
git push origin feature-case-1
```

### Шаг 4. Создайте Pull Request (PR)
1. Перейдите на страницу репозитория на GitHub.
2. Вверху страницы появится желтая плашка с предложением сравнить ветки. Нажмите кнопку **Compare & pull request**.
3. Проверьте, что изменения направлены из вашей ветки (например, `feature-case-1`) в ветку `main`.
4. Напишите краткое описание того, что было сделано, и нажмите **Create pull request**.

---
*После создания PR проектный лидер проверит изменения, и они будут объединены с основной веткой!*
